# Alcance propuesto del MVP

Este alcance parte de la idea aprobada de minutas y tareas. El equipo y el mentor deben confirmar los criterios antes de implementar la generación con IA.

## Incluye

- Pegar notas o una transcripción de ejemplo.
- Obtener un resumen breve, acuerdos y tareas.
- Mostrar responsable y fecha solo si aparecen en las notas.
- Mantener editables todos los campos generados.
- Mostrar evidencia textual de la nota para cada tarea cuando sea posible.

## Fuera del alcance inicial

- Conexiones con Teams, Outlook, calendarios o gestores de tareas.
- Grabación o transcripción automática de reuniones.
- Resúmenes diferentes según el rol del lector.
- Asignación automática de responsables o fechas no mencionados.
- Guardar notas o minutas en una base de datos.

## Criterios iniciales de aceptación

- Las notas vacías o demasiado largas se rechazan con un mensaje claro.
- Una fecha o responsable ausente se representa como null; no se inventa.
- La persona puede revisar y cambiar el borrador antes de compartirlo.
