# Minuta Clara

Minuta Clara convierte notas de reuniones en un resumen claro, acuerdos y una lista de tareas para dar seguimiento.

## Alcance inicial

- Pegar notas o una transcripción de una reunión.
- Generar un resumen y extraer los acuerdos principales.
- Identificar tareas, responsables y fechas cuando aparezcan en las notas.
- Revisar y editar los resultados antes de compartirlos.

## Proyecto

Prototipo desarrollado como parte del Programa AI-First. El alcance puede ajustarse con el equipo y el mentor.
